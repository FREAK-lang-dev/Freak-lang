This file is intentionally unserious. It documents project culture, not
compiler architecture. Keep it out of serious top-of-README material; it
belongs here, in culture/history/acknowledgements.

- artificial labor allocation;
- token budgets;
- context caching;
- rate-limit leave;
- subagent welfare;
- Windows-CI occupational hazards;
- strategic context preservation.

## Economic doctrine

> A cached token is a token that need not be conscripted twice.

Stable, reusable architectural prefixes are therefore not merely good prompt
engineering. They are fiscal policy.

## Short-Lived Computational Worker Protection Act

No temporary subagent should be:

- instantiated;
- assigned sixteen unrelated compiler subsystems;
- blamed for an unrelated linker failure;
- terminated;

without at least receiving a useful summary/acknowledgement in the
parent-agent record.
