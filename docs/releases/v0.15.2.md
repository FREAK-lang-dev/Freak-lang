# FREAK 0.15.2

Release date: 2026-11-21. A patch release on top of 0.15.1 "Maverick". Everything that built on 0.15.1 still builds, and nothing changes behavior except the fixes below.

## Fixes

- **`hangar add` from a Git URL works on Windows.** Git writes its object and pack files read-only, and Hangar couldn't clean up its staging folder because of them, so the add failed. Hangar now clears the read-only flag on the file it is deleting and tries again. You no longer need the `hangar add <alias> --path <clone>` workaround.
- **C-style logic operators get a real error.** FREAK spells logical AND, OR and NOT as `and`, `or` and `not`. Writing `&&`, `||` or a prefix `!` used to produce a pile of unrelated errors (`expected '{', found '&'`, `this token cannot start an expression`, `missing '}'`). Now you get one error that names the FREAK word:

  ```
  error: '&&' is not a FREAK operator — logical AND is spelled 'and'
   --> main.fk:4:17
    |
  4 |     if exists() && ext() == ".html" {
    |                 ^ write 'and' here
  ```

  Write `if exists() and ext() == ".html" {`.

## Smaller changes

- `word.byte_length()` returns a word's size in UTF-8 bytes. In 0.15.x it gives the same result as `length()`. Use it where you mean bytes, so the code keeps its meaning under V4, where `length()` counts characters.
- Converting between `int` and `word` (`word_from_int`, `.to_int()` on plain decimals) skips the printf/strtoll machinery and is faster. The results are the same.
- The installed runtime ships two more V4 preview runtime files (`freak_v4_compiler_array_runtime.c/.h`). `freak doctor` now expects 37 runtime files.

## Upgrading

Install the same way as 0.15.1: the release binaries, `install.sh`, `install.ps1`, Homebrew, Scoop or WinGet. Projects, locks, caches and credentials from 0.15.1 carry over unchanged.
