# AUTHORS

FREAK does not keep a hand-curated list of names here. Authorship is recorded
in the Git history (`git shortlog -sne`), which is the only attribution
source this file trusts. No names below are asserted beyond what the history
shows, and no one has been added or omitted by editorial choice.

## AI assistance — honestly disclosed

Parts of this repository — code, diagnostics wording, tests, and
documentation — were produced with AI coding assistance, working alongside
human maintainers who reviewed, directed, and took responsibility for the
result. AI contributions are not separately itemized per commit: repository
policy keeps trailers (including AI-attribution trailers) out of commit
messages, so the history records the committing author, not the tooling used.

What this means in practice:

- A commit's author is the human (or bot account) in the commit header.
- That author vouches for the change regardless of how it was drafted.
- Review gates (self-review, independent review, CI) apply equally to
  AI-assisted and hand-written work.

## Crediting your work

Contribute under the identity in your commit header. If you want a name or
address change to propagate, fix it in your Git configuration — this file
will not track aliases.
